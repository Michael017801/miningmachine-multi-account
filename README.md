# OreFarm Console

**简体中文** ｜ [English](README.en.md)

多账号自动挖矿客户端，用于 [miningmachine.io](https://miningmachine.io/) 的批量账号管理。

## 这是什么

miningmachine.io 的挖矿是「按天签到」模式：每个账号每天启动一次，24 小时内自动产出 `$ORE`。手动管理多个账号意味着每天逐个登录、逐个点击，很容易漏掉导致断签。

这个客户端把整套流程自动化：批量建号、批量启动、到期自动续接、X 身份隔离管理，全部在一个界面里完成。

## 功能

- **批量建号** — 一次创建最多 50 个账号，4 路并发登录，50 个约 25 秒完成
- **自动续接** — 监控每个账号的会话到期时间，到期后自动开启下一轮 24 小时
- **独立会话隔离** — 每个账号独立 token、独立 X 登录态，互不干扰
- **X 身份绑定** — 内置授权窗口，每个账号可绑定独立的 X 身份并持久保存
- **一键导出** — 单个或批量导出账号数据
- **中英双语** — 界面右上角切换，选择自动记忆
- **实时日志** — 所有操作和异常在右侧面板实时输出

## 使用流程

1. **新建账号** — 点右上角「＋ 新建」，输入数量，等待创建完成
2. **绑定 X** — 点行内「绑X」，在弹出的窗口里登录 X 并授权
3. **启动挖矿** — 点「启动」开启该账号的 24 小时会话
4. **开启自动续接** — 点底部「开启自动续接」，之后无需人工干预
5. **定期查看** — 界面每 30 秒自动同步，余额和剩余时间实时更新

## 说明

每个账号需要绑定一个 X 身份，一个 X 只能绑定一个账号。实际可管理的账号数量取决于你手上 X 账号的数量。
